# Store metadata

Fastlane-layout metadata, the format both
[IzzyOnDroid](https://gitlab.com/IzzyOnDroid/repo) and
[F-Droid](https://f-droid.org/docs/All_About_Descriptions_Graphics_and_Screenshots/)
read.

Kept here so a submission needs no extra work: point either at this repo and
the listing builds itself. Screenshots are the ones in `docs/screenshots/`,
numbered because F-Droid orders them by filename.

Update `full_description.txt` whenever the README's feature list changes — they
say the same thing to two audiences and are easy to let drift.
